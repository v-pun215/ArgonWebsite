Information

If you get a warning that the app cannot be opened, click 'Run Anyways'. You may need to click 'More info' to see this option. This warning is entirely harmless and only shows because the app is not signed. Signing it would cost me a lot of money.

Run ArgonMac.sh with "sh ArgonMac.sh" (without the double-quotes). After that go through the installer. After the installer is finished open the newly mounted disk named Argon Installer and drag Argon to the Applications folder.

To run on Linux, download the zip file. Execute "pip3 install -r requirements.txt". After that run main.py using "python3 main.py". An installer for Linux is still being developed.
